# Apple Music – 10-Sekunden-Promo (inoffiziell)

Inoffizielles Fan-Video, 1920×1080, 30 fps, 120 BPM, synthetisierter Soundtrack. Schnitte liegen auf dem Beat.
Songs, Künstler und Cover sind erfunden; Apple-Logo und App-Icon werden nicht nachgebildet.
Apple Music ist eine Marke von Apple Inc.

▶ **Video:** [`out/apple-music-10s.mp4`](out/apple-music-10s.mp4) · Storyboard: [`out/storyboard.png`](out/storyboard.png)

| Zeit | Szene |
|---|---|
| 0–2 s | Diagonal scrollende Cover-Wand: „Über 100 Millionen *Songs.*“ |
| 2–4 s | Leuchtende Kugel mit 3D-Partikelringen, Schockwellen im Takt: „Spatial Audio – mit Dolby Atmos. Dazu Lossless Audio.“ |
| 4–6,5 s | Player + Live-Songtexte, Wort für Wort hervorgehoben (Melodie folgt den Wörtern) |
| 6,5–8,5 s | Laptop, Tablet, Handy, Uhr mit Equalizer im Takt: „Auf all deinen *Geräten.*“ |
| 8,5–10 s | Schriftzug „Apple Music“ mit Lichtschimmer: „*Hör, was dich bewegt.*“ |

## Rendern

```bash
node audio.cjs     # → out/soundtrack.wav
node render.cjs    # → out/apple-music-10s.mp4
```
