# Brag-Plan: „Wissen in 30 Sekunden“ – Staffel 1

**Was ist es?** Eine Reihe von 3D-Erklärvideos, je 30 Sekunden, komplett aus Code gebaut (HyperFrames, Three.js, GSAP) – ohne Kamera, ohne Schnittprogramm.
**Für wen?** Neugierige, die auf dem Handy in einer halben Minute verstehen wollen, wie etwas funktioniert.
**Was hebt es ab?** Röntgenblick ins Innere, echter Code erzeugt jedes Bild (z. B. die Feldlinien aus der Dipol-Formel), eigenes Sounddesign, Faktencheck vor dem Rendern.
**Neu seit dem letzten Brag:** Folge 3 (AirPods) – die erste Folge mit Sounddesign.
**Stärkster Moment:** Die Feldlinien wachsen im Video, während daneben genau der Code dafür erscheint.
**Gag:** Bei „Ergebnis: Stille.“ im AirPods-Video setzt auch die Musik des Brag-Videos einen Schlag lang aus.
**Ton:** `default`, im Look der Reihe (Anthrazit, Inter, eine Akzentfarbe pro Szene).
**Share-Zeile:** Drei Fragen, je 30 Sekunden, jedes Bild aus Code.

**Nur saubere Quellen:** Folge 1 (Kontaktlos), Folge 2 (Blood Falls), Folge 3 (AirPods, eigenes Ohrhörer-Modell). Die privaten Videos mit dem Modell ungeklärter Herkunft kommen nicht vor.

**Format:** 1920×1080, 30 fps, 20 s. **Musik:** 150 BPM (Schlag 0,4 s, Takt 1,6 s), a-Moll. Alle Schnitte auf Schlägen.
